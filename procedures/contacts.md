## 五、簽核鏈速查

### 老師不在所上時的授權用印

若文件需要**老師簽名或蓋章**,但老師不在所上,可先請老師**授權用印**。
做法是用 email 或訊息向老師確認並清楚列出**哪些文件需要授權用印**;
取得老師同意後,將該封信或訊息截圖等證明文件出示給**出納**,即可辦理授權用印。

- **請購單**:採購人員(專任助理)→ 兼辦會計(于仙/彥玲)→ 總務(芳如)→
  〔資訊設備:電腦室覆核〕→ 送瀚霈 → 瀚霈依當時副所長或所長誰在所上轉送核章 →
  所長/副所長集中批公文與請購(通常需等幾天)→ 蓋章後回到孟君 → 助理向孟君領回。
- **報帳黏存單**:經辦人(專任助理)→ 驗收及證明人(老師)→ 經辦單位主管(孟君)→
  經費所屬會計。
- **書函/函稿**:先給孟君確認 → 印出 → 老師簽名 → 如涉及經費,會計簽名 →
  孟君 → 所長蓋章後返還 → 宜珊。
- **簽呈**:先給孟君確認 → 印出 → 老師簽名 → 會計、總務簽名 →
  孟君 → 所長蓋章後返還 → 執行簽呈申請事項。
