# 驗收、報廢與汰舊換新

## 概述

本檔涵蓋與設備/財物相關、但不屬於「請購→報帳」主線的三個程序:

- **驗收**:購買財物報帳時需附實物照片,必要時附驗收單並請廠商簽名。
- **報廢**:已屆使用年限的舊財物辦理報廢;找總務辦理。
- **汰舊換新**:以汰舊換新名義購買財產後,報廢財產清冊上的同品項舊財產(財產移動單)。

> 請購見 `procurement.md`;報帳見 `reimbursement.md`。購買物品原則上以**汰舊換新**為原則,
> 因此請購新品**之前**通常要先完成(或安排)舊品報廢。

---

## 一、物品及財產驗收

### 所需文件

- **實物照片**:購買財物相關報帳時,一律要**拍下實物照片**,放在空白 Word 檔上印出,附在報帳文件中。
- **驗收單**(視情況):若是維修或其他特別情況,請購階段時**總務會交代要多附上驗收單**;需要時才附。

### 逐步流程

1. 若需附驗收單,**購買財物時可事先把驗收單內容填好**。
2. **交貨時請廠商簽名**。若時間上無法配合,可請電腦室(力允)幫忙轉交廠商簽名。
3. 若為**線上刷卡付款**、廠商無法到場簽章,可在驗收單備註欄註明
   「因為線上刷卡購買,故無廠商之簽章」,並附上產品照片。
4. 依標準順序完成:**請購 → 採買 → 驗收 → 開發票 → 報帳**。
5. 報完帳後,需要列出物品或財產的項目;**總務會打電話通知助理去領貼紙**,
   領到後**貼在該物品/財產上**。

### 驗收單簽章欄位

| 角色 | 由誰擔任 |
| --- | --- |
| 記錄 | 專任助理 |
| 廠商(代表 / 專任工程人員) | 廠商負責人 |
| 主驗人 | 老師 |

### 常見錯誤與例外情況

- **驗收單日期**:絕對不可以早於採買日期,亦不可以晚於報帳日期。
- **忘了拍實物照片** → 財物報帳一定要附照片,補拍後放空白 Word 印出。
- **廠商不在場無法簽驗收單** → 請電腦室力允協助轉交簽名。
- **線上付款沒有廠商章** → 在驗收單備註欄註明「因為線上刷卡購買,故無廠商之簽章」,
  並附上產品照片。

## 二、報廢

### 概述

報廢並非請購報帳的一環,不過與設備採購相關,**承辦窗口是總務**。已過使用年限的財物才可報廢:

- **財產**:使用年限 **5 年**。
- **物品**:使用年限 **2 年**。

### 事前準備

- 若要知道老師目前有哪些財產/物品、哪些已屆使用年限,可找**總務芳如**列印**財物清單**查看。
- 財稅中心存有老師四台螢幕,遇到清點財產時須填寫「**財物存置院外申請單**」與「**保管同意書**」
  ——**只需老師簽名,不要填寫日期**。

### 逐步流程(以物品為例)

1. 找到要報廢的物品,**確認上面貼的物品編號**。
2. 填寫**報廢單**(欄位見下)。
3. 請**老師在「保管人」欄位簽名**。
4. **帶著要報廢的實物與報廢單,一起繳給總務**即可。

### 報廢單欄位(範例)

| 欄位 | 範例值 |
| --- | --- |
| 保管人(User) | (老師簽名) |
| 存放地點(Storage Place) | 經濟所 B308 室 |
| 報廢財產/物品名稱 | 無線鍵盤滑鼠組 |
| 報廢財產/物品編號 | 6010318-0001-0003133 |
| 報廢原因 | ■財產、物品已逾使用年限且不堪使用 / □其他 |
| 使用年限 | 2 年 |
| 購置日期 | 107 年 6 月 19 日 |
| 備註 | — |

承辦流程(簽核):**保管人簽名 → 財產管理人(Property administrator)→ 核准人(Approver)**。

### 常見錯誤與例外情況

- **大型財產(如沙發)**:不能自己搬,要**跟總務約時間**,由他們來處理搬運。
- **未達使用年限就想報廢** → 不可;財產須滿 5 年、物品須滿 2 年才辦報廢。
- **保管同意書/財物存置院外申請單填了日期** → 錯,該類文件只需老師簽名、**不填日期**。

## 三、汰舊換新

### 概述

如果購買財產是以**汰舊換新**的名義,則在購買新產品之後,需要將**財產清冊上同品項且已超過
使用年限**的財產報廢。

### 請購單勾選時機

請購單中「汰舊換新」的選項,**只有在使用經濟所上「4 年 12 萬」的經費時才需要勾選**。

### 逐步流程(財產移動單)

1. 確定要報廢後,**通知總務領取財產移動單**。
2. 請**老師在財產移動單上簽名**。
3. 將要報廢的**財產移交給電腦室**,並請其**蓋章**。
4. 財產移交給電腦室後,將財產移動單**交還給總務**。
5. 最後找**所長秘書孟君蓋所長章**,將財產移動單**交還給總務**,報廢流程即完成。

### 與請購的銜接

- 請購單上可敘明汰舊換新緣由,例如:「…原有擴充集線器(物品編號:6010306-0005-0003048)
  已屆年限,且傳輸效率下降不便使用,將辦理報廢。」(詳見 `procurement.md` 設備採購一節。)
