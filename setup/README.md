# setup — 各家 AI 工具的安裝輔助檔

本資料夾放的是**安裝時要複製到別處的檔案**，不是流程內容。流程內容一律在上層的
[`../SKILL.md`](../SKILL.md) 與 [`../procedures/`](../procedures/)；安裝步驟見根目錄 [`README.md`](../README.md)。

| 檔案 | 用途 |
| --- | --- |
| `codex-prompt.md` | 複製成 `~/.codex/prompts/lab-admin.md`，之後在 Codex 打 `/lab-admin` 就能用；檔案第一段的路徑要改成本 repo 在你電腦上的絕對路徑 |

其他工具不需要額外檔案：

- **Claude Code / Claude.ai / GitHub Copilot** 讀 `../SKILL.md`
- **Codex / Cursor / Gemini CLI** 讀 `../AGENTS.md`（在本資料夾裡開啟工具即自動生效）
