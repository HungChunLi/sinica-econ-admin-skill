# 研究室設定（範本）

> **這是範本檔，請勿直接填寫。**
> 第一次使用本 skill 時，把本檔在同資料夾內複製成 `lab-profile-<年度>.md` 再填寫：
>
> ```powershell
> # Windows PowerShell（在 repo 根目錄執行）
> Copy-Item lab-profile\lab-profile-example.md lab-profile\lab-profile-2026.md
> ```
>
> ```bash
> # Mac / Linux
> cp lab-profile/lab-profile-example.md lab-profile/lab-profile-2026.md
> ```
>
> **檔名規則**：`lab-profile-<年度>.md`；同一年度內若要改版就加序號（`lab-profile-2026-2.md`）。
> AI 一律讀**最新那一檔**；舊檔留著供回查「去年那筆錢是用哪個代碼報的」。
>
> `lab-profile/` 底下**數字開頭**的檔案都已列在 `.gitignore`，**不會被 commit 也不會上傳 GitHub**，
> 可放心填入真實姓名、帳號與金額。本檔（`-example.md`）則會進版控，
> **永遠只放 `〔佔位符〕`，不要填真實資料**。
