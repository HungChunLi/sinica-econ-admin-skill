# 文書範本

本資料夾存放行政流程會用到的表單與範本，供 AI 助手直接讀取使用。分兩類，處理方式不同。

## A. 官方空白表單（不存檔案，一律連結所內專區）

黏存單、支出證明單、借據、驗收單、報廢單、財產移動單、出國申請表、學術交流申請表、
國外學者來訪經費申請表、國科會經費變更申請表、聘僱申報表等一般用途表單**規則年年改**，
本 repo 不保存副本，以免用到過期格式。
每次使用前，一律到下列頁面現場下載最新版：

- 經濟所所內專區：<https://www.econ.sinica.edu.tw/ioecin/pages/126>
- 出國核准表：因公出國系統（見 `../procedures/travel.md`）
- 對照哪個流程要用哪張表，見 `../SKILL.md` 的路由表；流程細節在 `../procedures/`。

> 例外：**請購單、電子勞務(訂閱軟體)專用的請購單與支出憑證黏存單**已由研究室整理成
> 內建計算公式的客製化版本，存放於 `lab-templates/`（見下方 B 類），不受此條限制。

## B. 研究室自訂範本（存放於 `lab-templates/`）

由研究室自行維護、格式相對穩定的範本，包含空白請購單、電子勞務(訂閱軟體)專用
請購單/憑證黏存單、勞務承攬文件、學習活動紀錄、國外學者收據、保險投保申請書、公文簽呈範本等。
完整清單、目前已提供檔案與仍待補齊檔案,見 [`lab-templates/README.md`](lab-templates/README.md)。
