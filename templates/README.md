# 文書範本

本資料夾存放行政流程會用到的**實體範本檔案**，供 AI 助手直接讀取使用。
對照哪個流程要用哪張表，見 `../SKILL.md` 的路由表；流程細節在 `../procedures/`。

> ⚠️ **本資料夾會進版控並上傳 GitHub。** 放進來的檔案不得含有真實姓名、身分證字號、
> 戶籍地址、聯絡電話、帳戶資料、計畫代碼／計畫編號等資料。已填寫的實際文件請留在
> 研究室自己的雲端（位置見 `../lab-profile/` 第 3.3 節）。
>
> Word 檔另需清除 **Office 中介資料**（作者、最後儲存者）——這些不顯示在文件內容上，
> 但存在檔案屬性裡。做法：Word →「檔案 → 資訊 → 檢查文件 → 全部移除」。
