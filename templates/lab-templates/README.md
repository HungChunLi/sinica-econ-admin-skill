# 研究室自訂範本

本資料夾只放**格式相對穩定、可以直接重複套用**的實體檔案。
官方表單若規則或格式可能更新,原則上不要存副本,每次到所內專區或對應系統下載最新版。

> ⚠️ **本資料夾會進版控並上傳 GitHub。** 放進來的檔案**不得**含有真實姓名、身分證字號、
> 戶籍地址、聯絡電話、帳戶資料、計畫代碼／計畫編號等資料。已填寫的實際文件請留在
> 研究室自己的雲端(位置見 `../../lab-profile/` 第 3.3 節)。
